# UI + College Isolation Upgrade

- Official email domain auto-detects listed colleges during Student and Organization registration.
- Detected college is locked in the registration form to prevent accidental cross-campus assignment.
- Registration context independently re-checks email domain before saving the account.
- Organization dashboard and applications remain filtered by `collegeCode`.
- Student dashboard shows four core workspaces first; secondary tools stay behind Show More.
- White-first visual system uses soft emerald/amber/warm-neutral contrast.
- Workspace cards use hover tilt and click transition before navigation.
